# @cmtk/core

The engine of the [Complete Migration Toolkit](https://github.com/samuelnyamukapa/complete-migration-toolkit): cases, adapters, expectations, comparison, the drift ledger and reports.

Most people want the `cmtk` command instead: `npx cmtk`. The frozen formats are in [docs/FORMATS.md](https://github.com/samuelnyamukapa/complete-migration-toolkit/blob/main/docs/FORMATS.md). This library's functions are not among them, and they can change between minor versions.
