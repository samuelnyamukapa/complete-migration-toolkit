# @cmtk/mcp

The [Complete Migration Toolkit](https://github.com/samuelnyamukapa/complete-migration-toolkit) as MCP tools, so an AI agent drives the toolkit as a person does. Agents propose and people decide: no tool can approve, sign, accept or decide anything.

```sh
npx @cmtk/mcp
```

It speaks MCP over standard input and output, so an MCP client starts it. You need Node.js 22.5 or later.
